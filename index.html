Почему обычный трекер здесь не помогает

Трекеры считают клики. А с Авито Работы кандидат приходит в чат: переписка, ссылка в мессенджере или СМС, регистрация через несколько дней. Цепочка рвётся, и цена кандидата остаётся неизвестной.

Вопросы

Нужно ли уметь программировать?

Нет. Код уже внутри таблицы. Настройка идёт через меню с подсказками: вставить ключи и пару ссылок.

Какие сети поддерживаются?

Любые, которые умеют отправлять постбек (GET-запрос). Для Pampadu ссылка собирается автоматически. Для других сетей нужно вписать макросы из их кабинета — это 5 полей.

Только для курьеров?

Нет. Направление — это любая вакансия в любом городе: курьеры, склады, такси, продажи. Курьеры Яндекс Еды просто добавлены готовым набором.

Где хранятся данные кандидатов?

Только в вашей Google-таблице, на вашем аккаунте. Мы их не видим и никуда не передаём.

Что нужно от Авито?

Ключи API (Client_id и Client_secret) из раздела для профессионалов в кабинете Авито. Без них таблица тоже работает, но статистику Авито придётся вносить вручную.

Таблица гарантирует доход?

Нет. Это инструмент учёта: он показывает, сколько стоит кандидат и какие объявления окупаются. Решения по рекламе принимаете вы.
