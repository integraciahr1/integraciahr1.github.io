Найм-трекер

Подключение за 15 минут

Делайте шаги по порядку на компьютере. Если где-то застряли — пришлите скриншот в Telegram, поможем.

  1. Создать свою копию таблицы
  2. Первичная настройка и ключи Авито
  3. Опубликовать веб-приложение
  4. Вставить адрес и проверить
  5. Завести направления
  6. Подключить постбек сети
  7. Панель на компьютере и телефоне

1Создать свою копию

  1. Откройте ссылку, которую прислали после оплаты, и нажмите Создать копию.
  2. Копия откроется в вашем Google Диске. Через 5–10 секунд вверху появится меню Найм-трекер (если нет — обновите страницу).

2Первичная настройка

  1. Меню Найм-трекер → 1. Первичная настройка.
  2. Google попросит разрешение. Выберите свой аккаунт → Дополнительные настройки → Перейти на страницу… → Разрешить.
  3. Введите лицензионный ключ из письма или сообщения после оплаты (вида NT-XXXX-XXXX). Один ключ работает в одной таблице.
  4. Таблица спросит ключи Авито — Client_id и Client_secret. Где взять: в кабинете Авито раздел для профессионалов → API / Интеграции → получить ключи.
Предупреждение «Приложение не проверено Google» — нормально: это скрипт внутри вашей собственной таблицы, он работает только с ней и с Авито. Ключи хранятся в настройках скрипта, а не в ячейках.

3Опубликовать веб-приложение

Это нужно, чтобы таблица принимала постбеки и работала панель.

  1. Меню Расширения → Apps Script.
  2. Справа вверху Начать развертывание → Новое развертывание.
  3. Шестерёнка у «Выберите тип» → Веб-приложение.
  4. Запуск от имени: Я. У кого есть доступ: Все. Нажмите Начать развертывание.
  5. Скопируйте URL веб-приложения — он заканчивается на /exec.

4Вставить адрес и проверить

  1. В таблице: Найм-трекер → 2. Вставить адрес веб-приложения, вставьте URL.
  2. Появится «Готово!» — значит всё связалось. Что ещё осталось сделать, видно во вкладке Настройки → «Готовность».
  3. Для уверенности: Найм-трекер → 3. Проверить постбек. Должно быть «Постбеки принимаются ✅».
  4. Нужна статистика за прошлые дни? Найм-трекер → Загрузить историю Авито, укажите дату. Грузится в фоне, таблицу можно закрыть.

5Завести направления

Направление — это вакансия в городе, например «Курьер — Москва». Вкладка Направления:

  • Работаю — галочка: направление появится в сводке и на панели.
  • ID объявлений Авито — номер из адреса объявления (цифры в конце ссылки). Несколько — через запятую.
  • Метка sub1 — короткое слово латиницей. Ставьте его в sub1 своей партнёрской ссылки для этого направления.
  • Выплата и EPL — из карточки оффера в сети.
Работаете с курьерами Яндекс Еды через Pampadu? Меню Найм-трекер → Добавить направления: курьеры Яндекс Еды — добавит 179 городов со ставками. Отметьте галочкой только свои.

6Подключить постбек сети

  1. Вкладка Сети, столбец Ссылка постбека.
  2. Pampadu: ссылка уже готова — скопируйте её в кабинете Pampadu в настройку постбека, метод GET.
  3. Другая сеть: откройте в её кабинете настройку постбека, там список макросов (слова в фигурных скобках). Впишите в строку сети макросы ID конверсии, статуса, выплаты и sub1 — ссылка соберётся сама.
  4. Если статусы сети называются необычно (например «1» и «2»), впишите их в столбцы «Оплачено / В холде / Отклонено».

7Панель на компьютере и телефоне

  1. В таблице: Найм-трекер → Открыть панель → кнопка Открыть панель. Панель откроется на компьютере уже подключённой.
  2. Внизу сводки нажмите Подключить телефон и наведите камеру телефона на QR-код — панель откроется на телефоне и подключится сама.
  3. Добавьте на главный экран: iPhone — «Поделиться» → «На экран Домой»; Android — ⋮ → «Добавить на главный экран».
QR-код и ссылку для подключения никому не показывайте — по ним можно смотреть и менять вашу таблицу.

Если что-то не так

Ключ не принят

Проверьте, что ключ введён полностью, вида NT-XXXX-XXXX. «Ключ уже используется в другой таблице» — значит, он активирован в другой копии; если вы пересоздали таблицу, напишите нам — сбросим привязку.

Где вкладки «Постбеки», «Конверсии», «Авито по дням»?

Они скрыты, чтобы не мешать. Меню «Найм-трекер» → «Показать подробные данные».

Нет меню «Найм-трекер»

Обновите страницу и подождите 10 секунд. Меню появляется только в вашей копии, не в исходной таблице.

«Google просит войти» при вставке адреса

В развертывании выбран неверный доступ. Расширения → Apps Script → Развертывание → Управление развертываниями → карандаш → «У кого есть доступ: Все» → Версия «Новая версия» → Развернуть.

Постбек не принят / в «Постбеках» пусто

Проверьте, что ссылка в кабинете сети скопирована целиком (с token=…), метод GET. Если меняли что-то в Apps Script — опубликуйте «Новую версию» развертывания.

Регистрация попала в «? метка»

Метка sub1 в ссылке не совпала ни с одним направлением. Впишите её в столбец «Метка sub1» нужного направления.

Авито не подключилось

Запустите «1. Первичная настройка» ещё раз и проверьте ключи. Ответы Авито видны во вкладке «Авито — ответы API».

Панель пишет «Неверный ключ»

Нажмите внизу сводки «Сменить ссылку» и вставьте ссылку из вкладки «Настройки» заново.
